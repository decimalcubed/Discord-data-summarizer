# Discord data summarizer VCV2
Complete rewrite of the legacy discord data summarizer that now includes a ton more information + shows VC and stream data
V2 Currently does not render any graphs, if you would like a graph of your message history (limited to 2020-2025, and only messages), you can download a legacy version (V1.2/V1.3)

# To use:
First, obtain a data package, if you already have one, skip this.
1. Go to 'Data & Privacy' in settings.
2. Scroll down to 'Request your data'.
3. Request a package with the 'Messages', 'Servers' and 'Your Activity' options enabled.
4. Wait to receive the package in your email.
5. Download and unzip it.

Download/Compile the data summarizer 
- You can do this by navigating to the 'Releases' section on this page
- If you wanna compile it idk figure it out urself im not explaining that here

Then, with your data package
1. Open DiscordDataSummarizerVCV2-{OS_arch}.exe
2. Copy+Paste the directory/path of the unzipped data package into it (E.G. C:\Downloads\Package)
3. Press enter
5. Wait a bit (On accounts with lots of data, this can take a few minutes)
6. The program should now display a TON of info for every message, vc, and stream event over the entire lifetime of your discord account

### Note:
The data package MUST have 'Messages', 'Servers' and 'Your Activity' options enabled, if it is missing any of these options, the program will fail.

If you already have a data packet, or are on cooldown to get a new data packet, and it doesnt have all of these options, but it DOES have the 'Messages' option enabled, you can download a legacy version (V1.3 and under) which wont show you as much message data, wont show vc/stream data, and only shows data for years 2020-2025, but it only requires the 'Messages' option.
